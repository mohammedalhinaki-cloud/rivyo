# المصحف المرتل — الشيخ أ.د. محمد برهجي

تطبيق استماع للقرآن الكريم كاملًا (114 سورة) بصوت **الشيخ أ.د. محمد برهجي** برواية **حفص عن عاصم — مرتل**،
مع **توقيتات الآيات الرسمية** من واجهة mp3quran، ومتابعة تلقائية لآخر موضع استماع، وتشغيل في الخلفية،
وسور تعمل دون إنترنت بعد تنزيلها. يعمل كتطبيق ويب (PWA) ويُبنى كتطبيق **أندرويد (APK)** عبر Capacitor.

> **قرار منتج (الإصدار 1.1.0): التطبيق صوت فقط — نص المصحف غير مُضمَّن إطلاقًا.**
> بطاقة الآية تعرض رقم الآية وتوقيتها، واختيار الآية يتم بإدخال الرقم أو من شبكة أرقام الآيات.

## ما تم التحقق منه فعليًا (بلا ادّعاءات)

| العنصر | القيمة | كيف تم التحقق |
|---|---|---|
| معرّف المقرئ في mp3quran | `21181` | بيانات mp3quran المنشورة في مستودعات مفتوحة (`data/audio/mp3quran.json`) |
| معرّف المصحف (رواية حفص مرتل) | `340` | المصدر نفسه، وهو نفس المعرّف المستخدم في واجهة التوقيتات (`read=340`) |
| مجلد التلاوة الرسمي | `https://server16.mp3quran.net/M_Burhaji/Rewayat-Hafs-A-n-Assem/NNN.mp3` | نفس المصدر أعلاه + مشغّلات مفتوحة المصدر (`murattel`, `Aya`) |
| فهرس توقيتات الآيات | `https://www.mp3quran.net/api/v3/ayat_timing?surah=N&read=340` | قائمة القراءات المتزامنة في مشروعين مفتوحي المصدر (تتضمن 340 = برهجي) |
| بيانات السور (أسماء/أعداد/جزء/سجدات) | 114 سورة، 6236 آية، 15 سجدة | تحقق آلي داخل `scripts/build-data.mjs` (بيانات وصفية فقط من حزمة تنزيل — بلا نص المصحف) |

> **تنبيه صريح:** لم أستطع الاستماع للملفات الصوتية ولا تشغيل التطبيق على جهاز أندرويد في بيئة التطوير.
> التحقق من أن الصوت هو «مسجد رسول الله ﷺ وقصر المنفصل» يعود إليك — المصدر الرسمي لدى mp3quran صحيح كما في الجدول أعلاه.
> **Warsh/الإصدارات الأخرى غير مستخدمة**: التطبيق مثبّت على مصحف واحد (حفص مرتل للشيخ برهجي) لتفادي أي التباس.

## الوظائف المنفّذة

- **قائمة السور الـ114** مع بحث فوري (الاسم العربي مع تطبيع الهمزات، النطق اللاتيني، رقم السورة) وتصنيف (مكية/مدنية/المحمّلة).
- **صوت فقط**: بطاقة الآية تعرض رقم الآية الحالية وتوقيت بدايتها/نهايتها — بلا أي نص مصحف مُضمَّن.
- **تشغيل من آية محددة**: إدخال رقم الآية («تشغيل من هنا») أو اختيارها من **شبكة أرقام الآيات** → يبدأ من بدايتها تمامًا حسب التوقيتات الرسمية.
- **تنقّل آية/سورة** تاليًا وسابقًا (والسابقة تعود لبداية الآية الحالية إن تجاوزتها بثانيتين).
- **حفظ آخر موضع تلقائيًا** (السورة + الآية + المللي ثانية) كل 1.5 ثانية، وعند الإيقاف، والتصغير، والإغلاق — يبقى بعد إغلاق التطبيق.
- **بطاقة «متابعة الاستماع»** في الرئيسية: تستكمل من الثانية نفسها، مع إمكانية حذفها.
- **تشغيل في الخلفية** مع أزرار شاشة القفل والإشعارات عبر MediaSession (تشغيل/إيقاف/تالي/سابق/تقديم وتأخير 10 ثوانٍ).
- **انتقال تلقائي** للسورة التالية عند انتهائها، مع إشعار داخل التطبيق (قابل للإيقاف).
- **إعادة الآية** حتى ×5، **تكرار السورة كاملة**، و**سرعة تلاوة** 0.75×–2×.
- **ثيم داكن/فاتح**، تصميم RTL كامل، خط قرآني مضمّن (Amiri Quran — رخصة OFL).
- **تنزيل السور** لتعمل دون إنترنت (في تطبيق أندرويد فقط): تنزيل أصلي مع نسبة تقدّم، إدارة المحمّلة، وحذف بتأكيد.
- **فشل مرن**: عند تعذّر الوصول للسيرفر الأساسي يجرّب المجلد البديل من واجهة mp3quran؛ وعند تعذّر جلب التوقيتات الرسمية يستخدم تقديرًا نسبيًا لأطوال الآيات **مع تنبيه ظاهر** في الواجهة.

## الحصول على ملف APK

### الطريقة 1 — تنزيل جاهز (تلقائي)

**رابط التنزيل المباشر (الإصدار 1.0.0):**

```
https://github.com/mohammedalhinaki-cloud/rivyo/releases/download/v1.1.0/quran-player-burhaji-1.1.0.apk
```

**أحدث نسخة تتحدّث تلقائيًا مع كل تعديل:**

```
https://github.com/mohammedalhinaki-cloud/rivyo/releases/download/apk-latest/quran-player-burhaji-1.0.0.apk
```

(الحجم ≈ 5.5 م.ب — يعمل على أندرويد 7.0 وأحدث، `minSdk 24`)

كل تعديل على مجلد `quran-player` يُشغّل بناءً تلقائيًا على GitHub Actions ويُحدِّث هذا الملف:
- صفحة الإصدارات: <https://github.com/mohammedalhinaki-cloud/rivyo/releases> → إصدار **«أحدث نسخة APK (بناء تلقائي)»**.
- أو من تبويب **Actions → بناء APK → Artifacts → quran-player-apk** (يتطلب تسجيل دخول GitHub، ويُحذف بعد 90 يومًا).

عند التثبيت: يطلب أندرويد السماح بالتثبيت من مصدر غير معروف — فعّل الخيار ثم ثبّت.

### الطريقة 2 — بناء محلي
```bash
cd quran-player
npm ci && npm run build       # يبني نسخة الويب
npx cap sync android          # ينسخها إلى مشروع أندرويد
cd android && ./gradlew assembleRelease
# الناتج: android/app/build/outputs/apk/release/app-release.apk
```
المتطلبات: Node 22+، Java 21، Android SDK (compileSdk 36).

### الطريقة 3 — من Android Studio
```bash
cd quran-player && npx cap sync android && npx cap open android
```

### توقيع النسخة
- المفتاح المستخدم في CI: `android/keystore/quran-release.p12` (داخل المستودع ليعمل البناء التلقائي بلا أسرار).
- كلمة السر الافتراضية: `QuranPlayer2026!`، والاسم المستعار للمفتاح: `quran` (يمكن تجاوزها عبر متغيري البيئة `QURAN_KEYSTORE_PASSWORD` و`QURAN_KEY_ALIAS`).
- بصمة الشهادة (SHA-256): `CA:1A:3E:4D:BC:CD:1F:A7:35:6D:47:52:20:11:DB:E4:D2:C6:DA:80:B9:60:0B:EC:A3:50:45:87:D4:18:EC:FC`
- ⚠️ **للنشر على Google Play** يجب إنشاء مفتاح خاص بك والاحتفاظ به خارج المستودع؛ تغيير مفتاح التوقيع يمنع تحديث نسخة مثبّتة مسبقًا.

## ما لم يُنفَّذ (بصراحة)

0. **نص المصحف غير مُضمَّن عمدًا** (طلب المنتج): التطبيق صوت فقط. البيانات الوصفية للسور (الأسماء/الأعداد/الجزء/السجدات) فقط هي المضمّنة.
1. **لا يوجد صوت مضمّن داخل الحزمة**: التلاوة تُبَث من خوادم mp3quran. لتضمين الملفات كاملة يعمل التطبيق من أول تشغيل بلا إنترنت يُنزَّل كل سورة مرة واحدة (زر التنزيل) — أو تضمين ~1.5 جيجابايت من MP3 في المستودع وهو ما لم أفعله (حدود المستودع والترخيص).
2. **لم يُختبر على جهاز أندرويد فعلي**: بيئة العمل هنا بلا Java/Android SDK، فبُنيت النسخة على GitHub Actions. سلوك «التشغيل بالخلفية» و«الصوت مع إطفاء الشاشة» مبني على MediaSession + `setMediaPlaybackRequiresUserGesture(false)` في Capacitor، ويحتاج تجربة حقيقية للتأكيد (بعض شركات الهواتف تُنهي التطبيقات بقوة في الخلفية؛ استثنِ التطبيق من توفير الطاقة عند الحاجة).
3. **مؤشرات أندرويد الأصلية**: الإشعار/شاشة القفل يعملان عبر MediaSession في WebView، وليس عبر خدمة أمامية أصلية (Foreground Service).
